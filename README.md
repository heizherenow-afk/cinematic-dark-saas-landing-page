# Cinematic Dark SaaS Landing Page Template

A high-performance, dark-mode SaaS landing page template with cinematic animations, smooth shaders, tactile buttons, testimonial marquee, and interactive UI components.

## 🚀 Quick Start

Run the local server:
```bash
npm start
```
Or directly with Node.js:
```bash
node server.js
```

Open your browser at:
`http://localhost:3000` (or `http://localhost:3002` if port 3000 is occupied).

## ✨ Features
- **Cinematic Visuals**: Deep dark mode aesthetics, radial ambient glow gradients, and progressive blur overlays.
- **Full Interactivity**: Framer Motion spring physics, tactile pressed states, and Radix UI dropdown menus.
- **Dynamic Platform Detection**: Automatically detects OS (Windows, Linux, macOS) for downloads.
- **Self-Contained**: Complete fonts (Geist, Syne), SVG icons, and media bundled locally.
